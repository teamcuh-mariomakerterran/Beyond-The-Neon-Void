ORIGIN
This is an original bitmap font. Every glyph was drawn by hand on a 5x7 pixel
grid specifically for Brian Moore's games (Beyond The Neon Void / Black Doctrine).
It is NOT derived from, traced from, or converted from any existing font,
including "Press Start 2P" or any other third-party typeface. No third-party
font files, outlines or glyph data were used. The glyph data lives in
glyphs.py / splash3.py and is rendered by build.py / render.py.
