# Brian's PixelLab gun objects (source)

Downloaded from his PixelLab objects (GET /objects/{id}/spritesheet, free), 2026-11-08: each folder has the 8-rotation sheet, its layout JSON and the object's details. `index.json` maps folders to object ids. Game art sets are made from these by `tools/gear/import_pixellab_gun.py` into `assets/gear/weapons/<slug>/`.

Not found under the given name: `cyber_rifle_001`.
