Ad slides for the living signage (Signage "ads" feed and playlists in data/signage.json).

  <name>.png          a still slide, 192x96 (2:1), shown for 5 s
  <name>/             an animated slide: numbered frames (1.png, 2.png ... or name_01.png ...)
  <name>/ad.json      optional {"fps": 8, "hold": 6}  (hold = seconds on screen)

Playlist entries match these names (wildcards work: kitsune_*).
